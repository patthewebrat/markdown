# Markdown Magic ✨

A beautiful, real-time bidirectional markdown-HTML editor built with Vue.js. Edit markdown and see HTML instantly, or edit HTML and see markdown update automatically.

## 🚀 Features

- **Bidirectional Editing**: Edit markdown or HTML, both sides update in real-time
- **Dual Toolbar System**: Markdown formatting buttons on the left, HTML formatting buttons on the right
- **Beautiful Typography**: Clean, readable styling with proper syntax highlighting
- **No Build Required**: Pure HTML/CSS/JS - just open and use
- **Cross-Browser**: Handles contenteditable differences across browsers
- **Format Preservation**: Paste HTML content and keep all formatting
- **Contenteditable HTML Editor**: Rich text editing with live markdown conversion

## 🎯 Quick Start

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start editing!

No installation, no build process, no dependencies to install.

## 🛠️ How It Works

- **Left Panel**: Markdown editor with dedicated markdown formatting toolbar
- **Right Panel**: Live HTML editor that's fully editable with HTML formatting toolbar
- **Dual Toolbars**: Markdown formatting buttons on the left, HTML WYSIWYG buttons on the right
- **Real-time Sync**: Changes in either panel instantly update the other
- **Smart Paste**: HTML content pasted into the HTML editor preserves formatting

## 📝 Supported Markdown Elements

- Headers (H1-H6) with automatic styling
- **Bold** and *italic* text formatting
- `Inline code` with syntax highlighting and fenced code blocks
- Lists (ordered and unordered) with proper nesting
- Links and images with hover effects
- Blockquotes with custom styling
- Tables with responsive design
- Horizontal rules and line breaks
- GitHub Flavored Markdown features
- Cross-browser contenteditable support

## 🎨 Technical Stack

- **Vue 3** (CDN version - global build)
- **marked.js v16** for markdown parsing with GitHub Flavored Markdown support
- **turndown.js** for HTML to markdown conversion
- **Contenteditable API** for rich text HTML editing
- Pure CSS for styling with responsive design
- No build tools or compilation required

## 🌟 Use Cases

- **Documentation Writing**: Draft markdown docs with live preview
- **Content Creation**: Write blog posts or articles
- **HTML Learning**: See how markdown translates to HTML
- **Quick Formatting**: Convert between markdown and HTML formats
- **Note Taking**: Rich text notes with markdown portability
